THINKING DESKTOP · 下载 / 安装

把一句话交给 AI，装好壁纸。

复制下面的指令，粘贴到任意 AI 桌面端会话（DSH / Kimi / ChatGPT / Claude / Gemini…）。它会下载对应系统的 Thinking Desktop、检索本机已安装的 AI 客户端、一键绑定并启动，最后弹出控制台。你不用敲命令，也不用改配置。

macOS 13+ · Windows 10/11 用户级安装 · 无需管理员 只监听 127.0.0.1

AI 会替你做什么

  

    
01 · 下载按系统取安装包：macOS 用便携 tar.gz（无需 sudo），Windows 用 zip。

    
02 · 检索安装后读取本机探测结果，找出已安装的 AI 桌面端与可用通道。

    
03 · 绑定把检索到的客户端逐个绑定到壁纸，切到综合形态。

    
04 · 启动注册登录自启、启动服务与壁纸，并弹出控制台。

  


  
安装前后

  

    
    
      
  • 需要 Node.js 20+（脚本会自动用 Homebrew / winget 安装；也可先自行安装）。
    • 
      
  • Windows 壁纸宿主需要 .NET 8 SDK 与 WebView2 Runtime；脚本会尝试补齐（系统组件可能弹 UAC）。
    • 
      
  • 首次显示壁纸后，在「系统设置 → 隐私与安全性 → 辅助功能」授权 Thinking Desktop Wallpaper，Gemini / ChatGPT 才能读到文本。
    • 
    

    
    
      
  • 安装包会校验 sha256；服务只监听 127.0.0.1，写接口要本机令牌。
    • 
      
  • 重复运行是安全的：已安装则跳过下载，只重新检索并绑定客户端。
    • 
      
  • 不想让 AI 代劳？用下面的安装包手动装：macOS 双击 .pkg，Windows 解压后跑 win\\install.ps1。
    •
