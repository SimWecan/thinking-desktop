## 三、可优化清单

### P0（影响使用/明显体验）

1. **环带可被拖到几乎完全出屏**：实测 `x 0.01 / y 0.85 / 0.69×` 时桌面只剩左下一条弧。
   **已加提示**：圆心贴边（<0.12 或 >0.88）时控制台预览下方显示「圆心贴近屏幕边缘，桌面只会看到一段弧」，
   配合「重置位置」按钮可一键归位；是否硬性限制范围待你确认。
2. ~~悬停命中几何有 3s 延迟~~ **已修复**：壁纸页在 ring 变化时通过 `messageHandlers.geom`
   通知宿主立即刷新（日志 `geom refresh (ring changed)`），命中几何从「最多 3s」降到「下一次 1s 轮询内」。
3. **AX 读屏未授权**：Gemini/ChatGPT 只有 CPU 强度、没有文本。控制台已有入口，需要用户手动授权
   `bin/axread`（系统设置 → 辅助功能）。

### P1（体验/健壮性）

4. **Codex 通道静默**：`~/.codex/logs_2.sqlite` 最后一条是 09:55（12h 前），期间无新日志。
   需在真正使用 Codex 时复测映射是否仍命中；若日志表轮换（logs_3）需要跟随。
5. **托盘只在 Finder 前台时可见**（普通窗口层级，避免压住其它应用）。用户可能以为托盘消失；
   建议控制台加一条说明或「固定显示」开关。
6. **测试结束后真实事件会追加**：e2e 恢复数据后连接器重启，4s 内真实 DSH 事件计入（本次 +5）。
   属真实数据而非污染；若要严格零增量，可在恢复后再观察 2s 二次还原。
7. **预览与桌面不完全一致**：预览用 25fps 低负载模式且画布更小，缩放倍率下观感略有差异；
   可在预览角标注明「示意图 / 实时」。

### P2（锦上添花）

8. **环带文本模式**：当前默认 headline（首句），要看全文得改 `config/ui.json` 的 `ringText`；
   可在控制台加一个「首句 / 全文」开关。
9. **全分辨率自检图**：快照为半分辨率（960×540），做宣传图需要临时全分辨率入口。
10. **内存高水位**：heap 11–16MB，RSS 100–110MB（V8 预留），长时间挂机可观察是否需要定期重启。

## 四、结论

- 隔离注入测试：e2e 26/26、模拟 5 阶段、边界 12/12，均未污染真实数据（文本墙不变、统计 Δ=0）
- 用户实际使用：真实连接器、控制台、托盘、壁纸、悬停自检全部可用；空闲 CPU 0.3%、帧率 57–59
- 主要风险集中在 **P0-1 环带出屏** 与 **P0-2 几何刷新延迟**，其余为体验优化
